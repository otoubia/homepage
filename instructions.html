PUBLISHING YOUR HOME PAGE ON GITHUB (FREE) IN 8 STEPS

  1. Go to Gemini.google.com and log in with your Columbia UNI and password. Use the prompt below to generate your HTML code, then copy it.

    Highlighted fields are customized — upload your CV.

    My CV is attached.
    My LinkedIn profile is: https://www.linkedin.com/in/XXX.
    Create a home page based on this information (index.html).
    The vibe should be: professional and casual.
    Avoid emojis.
    The color scheme should be: blue, preferably Columbia blue.
    Navigation should be: streamlined.
    Include all the information from the CV on the home page. Keep the same section order, but feel free to create tiles or make navigation easier across sections.
    Create an index.html file that I can directly copy and paste to GitHub to deploy the page from there.
    Display the file in a window within the chat that makes it easy to copy and paste.
  2. Go to GitHub.com and create an account.
  3. Log in, go to "My repositories," click "New repository," give it a name (e.g., home_page), toggle "Add a README file" to On, and click "Create Repository."
  4. Inside your repository, click "Add file" > "Create new file." Name the file index.html. DO NOT USE ANY OTHER NAME.
  5. Paste your HTML code (from Step 1) into the edit window.
  6. Click "Commit Changes."
  7. Go to Settings > Pages. Under Source, choose Deploy from a branch, select branch main, and click Save.
  8. Within a minute, GitHub will give you a live URL — visit your site.

To update your page: go to <> Code, click index.html, then the edit (pen) icon. Make your changes and click "Commit changes." Click "History" (clock icon) and wait for the new commit to complete before refreshing your page.

Congratulations — your page is live!
